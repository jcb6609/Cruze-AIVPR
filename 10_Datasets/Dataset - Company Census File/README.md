- STATUS_CODE = A (Active)

Master list of active U.S. interstate motor carriers used for Cruze prospecting.

This dataset is used to identify prospective commercial trucking fleets for the Cruze AI Video Prospecting workflow. Selected companies are researched further for executive mapping, AI-generated video scripts, and personalized outreach.
